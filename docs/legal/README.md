# Legal and compliance drafts

These are working drafts for the owner and their advocate. None of them is
final, none has been reviewed by a lawyer, and none should be signed,
published or filed as it stands.

## How these were written, and what was not checked

The primary texts the drafts depend on could **not** be opened from the
environment they were written in (its network policy refused the Kenya Law
and ODPC websites):

- Data Protection Act, 2019 (Kenya Law, or the copy on kentrade.go.ke)
- Data Protection (General) Regulations, 2021
- Data Protection (Registration of Data Controllers and Data Processors)
  Regulations, 2021, and the ODPC Guidance Note on Registration
- ODPC Guidance Note for the Education Sector (December 2023)
- ODPC Guidance Notes for Processing Children's Data (2025)
- ODPC Guidance Note on Cross-border Data Transfers
- The ODPC guidance notes on data protection impact assessments and on consent

So: **no section numbers are cited**, and every statement about what the
law or the ODPC requires is marked **[VERIFY]**. Those statements come from
the brief the owner gave, or from practitioner summaries found by web
search (named where used), never from the texts themselves. Facts about
HouseMaster (what data it holds, where it is hosted, what the software
does) come from the code and are not marked.

Before relying on any draft, the advocate should check each [VERIFY]
against the current primary text and the ODPC's current guidance and forms.
